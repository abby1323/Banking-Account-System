# Banking-Account-System

Features & Functionalities:
1️⃣ User Management
✔ Create new accounts (Savings, Current)
✔ Store user details (Name, Account Number, Balance, etc.)
✔ Unique account number generation

2️⃣ Account Operations
✔ Deposit money
✔ Withdraw money (with balance checks)
✔ Transfer money between accounts
✔ Display account details

3️⃣ Transaction Management
✔ Maintain a transaction history (deposits, withdrawals, transfers)
✔ Display last N transactions

4️⃣ Interest Calculation (for Savings Accounts)
✔ Calculate and apply monthly/yearly interest

5️⃣ Security & Validation
✔ PIN/Password-based authentication for transactions
✔ Prevent negative balances and invalid transactions

6️⃣ File Handling (Optional for Persistence)
✔ Store account and transaction details in a file or database
✔ Load previous account details when restarting

7️⃣ Bonus Features 
✔ Implement multi-user access
✔ Add a simple CLI Menu for navigation
✔ Implement an Admin Panel to manage all accounts
